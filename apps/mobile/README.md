# KisanSetu mobile app

This is the Expo Router farmer-facing frontend. It uses NativeWind for the
Tailwind CSS styling used by `app/index.tsx`.

## Run locally

From this directory:

```bash
npm install
npm start
```

Use the Expo Go QR code, or run `npm run ios`, `npm run android`, or
`npm run web`.

## Checks

```bash
npm run typecheck
```
